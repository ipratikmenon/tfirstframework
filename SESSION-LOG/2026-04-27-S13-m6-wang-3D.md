## Embedding Strategy

2D Wang profiles embedded as 3D vortex tubes via:

```
u_3D(x,y,z) = u_2D(x,y)          (z-independent tube)
v_3D(x,y,z) = v_2D(x,y)
w_3D(x,y,z) = amp * |u_2D| * sin(m*z)   (weak z-perturbation, amp=0.02)
```

Leray projection (inside `set_ic_jax`) restores exact div u = 0 after
the perturbation is added. The perturbation energy is < 10% of base energy.
