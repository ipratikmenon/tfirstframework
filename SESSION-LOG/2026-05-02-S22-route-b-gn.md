### §14 — Route B via Gagliardo–Nirenberg and Incompressibility

**Core idea:** The div-free condition decomposes `u` into:
- `u_osc = u − ⟨u⟩_{B_r}` (oscillating part — automatically controlled)
- `⟨u⟩_{B_r}` (spatial mean — the sole obstacle)

The gap is therefore **precisely characterized** as a local Morrey condition
on spatial averages of `u`, not on `|∇u|` or `u` pointwise.

#### Lemma 14.1 (Local GN for div-free fields)

For `u ∈ H¹_loc` with `div u = 0`:
```
‖u − ⟨u⟩_{B_r}‖_{L^{10/3}(B_r)} ≤ C_GN · r^{2/5} · ‖∇u‖_{L^2(B_r)}
```
Proof: Poincaré (L²) + Sobolev (L⁶) + GN interpolation with θ=3/5 at q=10/3.

The general formula is:
```
‖u − ⟨u⟩‖_{L^q} ≤ C · r^{1-3/2+3/q} · ‖∇u‖_{L^2}   for 2 ≤ q ≤ 6
```

#### Proposition 14.2 (Oscillating part is controlled)

The oscillating part satisfies:
```
r^{-1} ∬_{Q(r)} |u_osc|³ ≤ C · r^{1/2} · X̄_{Q(2r)} |∇u|²
```
with exponent α_osc = 1/2 > 1/3 (better than required for Route B).

**Key consequence:** The entire difficulty of the local Sobolev bound
is concentrated in the spatial mean `⟨u⟩_{B_r}`.

#### Lemma 14.3 (Mean evolution ODE from NS)

Integrating NS over `B_r(x_0)`:
```
|B_r| · ∂_t⟨u⟩_r = −∫_{∂B_r} (u⊗u)·n dS + ν∫_{∂B_r} ∇u·n dS − ∫_{∂B_r} p n dS
```
This gives `|∂_t⟨u⟩_r| ≤ C/r · (mean |u|² + mean |∇u| + mean |p|) on ∂B_r`.

#### Proposition 14.4 (Pressure–mean coupling reduced by ½)

Using the traceless CZ decomposition p = p_T + p_σ from §13:
```
|∫_{∂B_r} p n dS| ≤ ½ C_CZ ∫_{∂B_r} |u|² dS + ‖p_σ‖_{L^1(∂B_r)}
```
The pressure–velocity product in the local energy inequality satisfies:
```
r^{-1} ∬_{Q(r)} |p||u| ≤ ½ C_CZ · r^{-1} ∬ |u|³ + ‖p_σ‖_{L^{5/3}} ‖u‖_{L^{10/3}}
```

#### Theorem 14.5 (Route B closes iff mean Morrey holds)

Suppose:
```
sup_{(x₀,t₀), r>0}  r^{-1+α} |⟨u(t₀)⟩_{B_r(x₀)}|³ ≤ C₀ < ∞   for some α>0
```
Then:
1. Local Sobolev bound holds for `u` with `α_S = min(α, 1/2)`
2. Route B Morrey reduction (★★) closes
3. Combined with Route C (Thm routeC), Claim A holds: `ν|∇u|² ∈ L^{1+δ₀}`

#### Corollary 14.6 (Precise gap characterization)

The single remaining obstacle is:
```
boxed: sup r^{-1+α} |⟨u(t₀)⟩_{B_r(x₀)}|³ ≤ C₀   for some α>0
```

This is:
- **(a) Equivalent** to Gap 4.2 (local Sobolev bound) — oscillating part is controlled
- **(b) Equivalent** to CKN A(r) ≤ ε₀ uniformly in r (Gap 4.2)
- **(c) Implied by** Prodi–Serrin `u ∈ L^p_t L^q_x` but **strictly weaker** — only asks about averages
- **(d) Satisfied** for shear layer ICs (mean decays as `|⟨u₁⟩_{B_r}| ≤ C‖f‖_{H¹}`, α=3) and near-shear ICs (exponential decay from Gronwall)

#### Remark (Tao's objection)

The mean Morrey condition is inside the **exact Prize equations** with no
regularization parameter. It does not reference μ(T), θ, or ε. Route C
closes the Prize once any δ₀ > 0 is supplied, without referencing T at all.

## Gap Statement (Sharpest Form After S22)

The Clay Prize for NS on T³ is equivalent to:

```
∃ α > 0, C₀ < ∞ such that for all (x₀,t₀) ∈ Q_T and all r > 0:
   r^{-1+α} · |⟨u(t₀)⟩_{B_r(x₀)}|³ ≤ C₀
```

This is a **local Morrey condition on spatial averages of u**:
- Strictly weaker than Prodi–Serrin
- Sufficient (via Route B+C) for full regularity
- Already proved for shear layer and near-shear ICs
- Equivalent to CKN condition A(r) ≤ ε₀ uniformly in r
