`layer2/test_self_similar_IC.py` were both created. One test was still
failing at session end. Fixed in S02:

**Bug: `dealias_23` broke Hermitian symmetry**
- Old: `f_hat[cutoff : N-cutoff, :]` — zeros row `cutoff` (k=+N/3) but NOT
  row `N-cutoff` (k=-N/3), breaking Hermitian symmetry of the real-field FFT.
- Fix: `f_hat[cutoff+1 : N-cutoff, :]` — keeps both k=±N/3, zeros |k|>N/3.
- Test updated to check `cutoff+1 : N-cutoff` to match what the function actually zeros.

**Bug: energy formula gave negative values for dipole vortices**
- Old: `E = 0.5 * mean(ψ·ω) * L²` — negative for dipoles (ψ, ω anti-correlated)
- Fix: `E = 0.5 * mean(|∇ψ|²) * L²` (spectral: `E = 0.5 * sum(|k|²|ψ_hat|²)/N²`) — always ≥ 0

**Bug: Laplacian sign convention in test**
- `spectral_laplacian_inv` solves (-Δ)ψ = f, so Δψ = -f
- Old test asserted `lap_psi ≈ f`; fixed to `lap_psi ≈ -f`
