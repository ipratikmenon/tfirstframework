## Work Done

### 1. route2_3D.py — Physics

Exact Prize NS (ν=const, div u=0) + auxiliary scalar θ:

```
∂_t u + (u·∇)u = −∇p + ν·Δu     div u = 0
∂_t θ + u·∇θ  = ν·Δθ + ν|∇u|²   θ(x,0) = 0
S_θ = ν|∇u|² ≥ 0  (viscous heating, always non-negative)
μ_eff(x,t) = ν + ε·f(θ)  (always ≥ ν)
```

Key design decisions:
- **RK4** for velocity (exact Prize equations, ν=const throughout)
- **Crank-Nicolson IMEX** for θ: implicit ν·Δθ in spectral space removes diffusion CFL:
  ```
  θ̂^{n+1} = (θ̂^n · (1 − ½dt·ν·k²) + dt · F̂_expl) / (1 + ½dt·ν·k²)
  ```
  where F_expl = −u·∇θ + S_θ (explicit part)
- **B-005 Nyquist fix** applied: Nyquist planes zeroed before Leray projection
- **θ ≥ 0 clipping** after each CN step (source always ≥ 0; negatives are pure numerical)

### 2. δ Estimator

`delta_from_theta()` computes H^s norms of θ for s ∈ {0, 0.5, 1.0, 1.5, 2.0, 2.5} and finds the largest s where ‖θ‖_{H^s} < 100·‖θ‖_{H^0}. Returns δ_est = s − 1 ≥ 0.
